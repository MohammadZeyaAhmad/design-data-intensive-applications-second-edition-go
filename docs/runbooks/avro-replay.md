# Avro schema lookup and archive replay

Run `make verify ID=C05-02` from the repository root. Go and Make are sufficient. The command verifies the full source inventory, regenerates schema copies/Go structs, runs race tests and writes the default report. Generated drift checks compare with the Git index/worktree; stage intended generated files before checking a new schema version. Never edit a published version in place.

The JSON report is `artifacts/avro.json`. Its `archive_directory` names a retained `avro-archives-*` child beside the report, containing `objects/<sha256>.avro` and `datasets/<name>.json`. Each default run creates a fresh child and six immutable datasets with three snapshots each. Keep a dataset's manifest and object together. Full writer schemas/defaults remain inside the OCF header; the current reader is selected separately. CI uploads those files with the report.

For a raw or single-object missing-writer failure, recover the exact published writer contract and register its immutable version. Do not substitute the latest schema or reconstruct one from today's Go struct/catalog. A standard single-object CRC may be ambiguous when full schemas differ only in stripped metadata. Recover the full published identity, then use `DecodePinnedSingleObject`; reject a mismatching standard header. An explicit identity is metadata, without a claim that a CRC authenticates a producer.

For archive replay, `Registry.ReplayDataset(ctx, directory, dataset, readerVersion)` verifies the manifest, complete file digest, embedded schema identity and every record. It only needs the chosen reader registered. A missing historical registry entry does not prevent OCF replay. Corrupt/truncated/oversized files, schema inconsistencies and invalid business records return errors without a successful prefix. Restore the exact known content object from a separate trusted copy; a sync marker does not repair data.

A different publication under an existing dataset name returns `ErrImmutable`; preserve the winner and use a new dataset name for changed content. Identical byte retries succeed. A failed/conflicting name publication may leave an unreferenced content object. The private lab does not automatically delete objects; identify references from all retained manifests before deliberately pruning an owned run directory. Temporary `.avro-publish-*` files can remain after a forced process kill; remove only known abandoned task-owned files.

Input uses a documented finite schema/data profile. Numeric width, default, alias or union incompatibility is a contract failure, rather than a reason to retry with an unchecked decoder. The pinned runtime checks every writer union branch at configuration time; a reader removing one branch can fail before reading a datum that selected another. Check the guide's union decisions when exchanging data with other implementations.

Use `cd labs && go test -run '^$' -fuzz '^FuzzBoundedAvro$' -fuzztime=8s -parallel=2 ./ch05/avro` for raw data and the same command with `FuzzBoundedContainer` plus `-fuzzminimizetime=100ms` for complete files/embedded schemas. The short minimization budget keeps a bounded run exploring more than its first novel full-container mutation. Tests also contain deterministic huge-count/decompression cases and independent wire vectors.

Wall/allocation samples include bounded preflight and actual writer/reader resolution. They exclude archive disk/compression/setup; archive file bytes are recorded separately. Generated mode uses ordinary generated Go structs with the same codec runtime, so compare the stated mapping boundaries. Larger exports, external registries, replicated retention and production deployment remain outside this local verification command.
